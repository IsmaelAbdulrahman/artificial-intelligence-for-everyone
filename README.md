# Artificial Intelligence for Everyone

The website for the book and its companion Android app, served by GitHub Pages
at <https://ismaelabdulrahman.github.io/artificial-intelligence-for-everyone/>.

**Artificial Intelligence for Everyone: A Practical Guide to Understanding,
Using, and Questioning AI** — First Edition, 2026, by Dr. Ismael Khorshed
Abdulrahman (Erbil Polytechnic University; PhD, Tennessee Technological
University).

24 chapters in four parts, 588 pages, 130 figures, 291 practice problems, 267
self-test questions and 296 glossary terms. Parts One to Three need no
programming; Part Four uses basic Python.

The companion app carries the whole book offline and adds **24 interactive
labs**, one per chapter, which compute their numbers on the device — a real
byte-pair tokenizer, word vectors learned from the book's own text, a retrieval
system over four documents, an injection range with switchable defences.

## What is in this repository

```
index.html    the site — one file, no build step, no dependencies
privacy.html  the app's privacy policy (Google Play requires a hosted URL)
assets/       cover, icons, screenshots, Open Graph image
book/         the Student Edition PDF
```

## Publishing it

GitHub Pages, from the `main` branch, `/ (root)` folder. Nothing to build:
push, and the site is live in a minute.
